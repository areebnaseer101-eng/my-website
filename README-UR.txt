AREEBA BLOOMS — ویب سائٹ چلانے کا طریقہ

1) ZIP کو Extract کریں۔
2) VS Code میں پورا "areeba-bouquet-website" فولڈر کھولیں۔
3) index.html کو Live Server کے ذریعے کھولیں۔
4) تمام تصاویر assets فولڈر میں موجود ہیں۔
5) بیک گراؤنڈ ویڈیو کے لیے اپنی اصل MP4 ویڈیو کو assets فولڈر میں رکھیں اور نام background.mp4 رکھیں۔
   ابھی موصول ہونے والی HTML فائل Pinterest کا محفوظ کیا گیا صفحہ تھی، اصل ویڈیو نہیں تھی۔
6) WhatsApp آرڈر آن کرنے کے لیے script.js کھولیں اور اوپر WHATSAPP_NUMBER = "" میں اپنا نمبر ملک کے کوڈ سمیت صرف ہندسوں میں لکھیں۔
   مثال: پاکستان کے نمبر کے لیے 923001234567 (اپنا اصل نمبر استعمال کریں)۔
7) ویب سائٹ میں category filters، dark/light mode، اردو/انگریزی ٹوگل، cart، custom bouquet form،
   order summary، copy order اور WhatsApp order flow شامل ہیں۔

نوٹ: قیمتیں نمونہ قیمتیں ہیں۔ اپنی اصل قیمتیں اور ڈیلیوری کی تفصیلات آرڈر لینے سے پہلے کنفرم کریں۔
آپ کی نئی تصاویر میں Car Bouquet کے لیے ایک واضح تصویر موصول ہوئی تھی، اس لیے اسے دستیاب تصویر کے ساتھ رکھا گیا ہے۔
